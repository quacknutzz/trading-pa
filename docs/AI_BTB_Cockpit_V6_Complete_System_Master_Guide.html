4. The Deep-Dive Math: Statutory Indian Friction Model

In Indian intraday cash trading, every trade pays mandatory fees. Understanding this math is the single most important key to net profitability:

Complete Round-Trip Cost Equation C(V, m):
C(V, m) = 1.18 * [min(20, 0.0003*V_buy) + min(20, 0.0003*V_sell)] ← Brokerage (₹20 cap) + 18% GST
         + 0.00025 * V_sell ← Securities Transaction Tax (STT on Sell)
         + 0.0000297 * (V_buy + V_sell) ← NSE Exchange Turnover Fee
         + 0.0000010 * (V_buy + V_sell) ← SEBI Turnover Charges (₹10 / Crore)
         + 0.0000300 * V_buy ← Stamp Duty (on Buy side)
         + m * 0.00050 * V_sell ← Market-Order Execution Slippage (m=1 for Market, m=0 for Limit!)
The Fixed Brokerage Trap (Small Accounts)

Brokerage is flat ₹20/order (₹47.20 round-trip with GST).
• On a ₹15,000 position, ₹47.20 = 0.31% drag!
• On a ₹1,00,000 position, ₹47.20 = 0.047% drag.
Taking 50 small trades/day pays ₹2,360/day in pure brokerage, guaranteeing account depletion regardless of strategy.

The Zero-Slippage Resting Limit Solution

Exiting at market ($m=1$) costs 0.05% in slippage (₹50 per ₹1 Lakh).
Exiting via a Resting Limit Target ($m=0$) costs ₹0 in slippage.
By scaling targets to dynamic ATR limits, maker limit fills doubled, saving ₹125+ per trade in pure execution friction.

The True Momentum Gate Algorithm (Active 09:15 to 09:45 AM) Dynamic Filter

1. Institutional Relative Volume: RVOL_TOD >= 1.25x (Rejects low-volume retail drifts)
2. Adverse Wick Rejection: Adverse_Wick / Total_Range <= 0.35 (Rejects shooting stars / hammers / failed breakouts)

3. Macro NIFTY Alignment: Morning NIFTY return >= -0.10% for BUY, <= +0.10% for SELL.
